# PharmaTech - Pharmacy Management & POS System 💊

نظام متكامل لإدارة الصيدليات ونقاط البيع والمخزون، مبني بلغة #C وقواعد بيانات SQL Server.

## 🚀 المميزات الرئيسية (Key Features)
- **نظام حماية وتراخيص متقدم:** قفل النظام وتوليد مفاتيح الترخيص بالاعتماد على المعرف الفريد للجهاز (HWID).
- **إدارة نقطة البيع (POS):** دعم قارئ الباركود، الفواتير الفورية، والتحقق التلقائي من توفر الكميات وتواريخ الصلاحية.
- **إدارة المرتجعات (Sales Returns):** استرجاع الأصناف وإعادتها للمخزون تلقائياً.
- **إدارة المخزون (Inventory Management):** تصنيف الأدوية، تتبع النواقص، وتنبيهات الأدوية منتهية الصلاحية.
- **إعدادات السيرفر الديناميكية:** واجهة مستقلة لربط واختبار الاتصال بخادم SQL Server محلياً أو عبر الشبكة.

## 🛠 التقنيات المستخدمة (Tech Stack)
- **Programming Language:** C# (.NET WinForms)
- **Database:** Microsoft SQL Server (`POS_InventoryDB`)
- **Architecture:** Tiered Architecture (DataAccessLayer)
- **Deployment:** Inno Setup Compiler
- **Version Control:** Git & GitHub
